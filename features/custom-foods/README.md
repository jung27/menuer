# 사용자 지정 음식

- `/custom-foods`: 계정별 음식 목록, 최신순 20개씩 조회.
- `/custom-foods/new`: 음식 추가. `?edit=<id>`로 같은 편집 화면에서 수정.
- `/custom-foods/explore`: 공개 음식 목록과 음식 이름·만든 사람 검색. 로그인 없이 열람 가능.
- `/custom-foods/explore/:id`: 질감 미리보기와 내 음식에 추가. 가져올 때 로그인 필요.
- `/mypage`: 현재 계정 닉네임·이메일 조회.
- 홈과 각 화면의 프로필 버튼: 마이페이지 / 사용자 지정 음식 / 로그아웃.
- 미로그인 시 로그인 링크를 표시하며, 보호 화면 접근 시 로그인 화면으로 이동합니다.

`SensoryObject`의 `customConfig`를 그대로 사용합니다. 맛 6개, 모든 물리 속성 13개, 겉면·속면 색상 2개와 질감 종류(튀김·고기·면·밥·빵·국물·채소)를 저장합니다. 색상은 40개 팔레트와 브라우저 색상 선택기로 고릅니다. 맛 수치와 물리 수치는 독립적으로 편집합니다. `PHYSICS_FIELDS`가 원본 타입의 모든 숫자 속성을 포함하도록 타입으로 확인합니다. 이전 저장 음식에 질감 종류가 없으면 기본 고기 질감으로 불러옵니다.

그림은 PNG/JPG/WEBP를 받아 브라우저에서 최대 512px WEBP로 줄입니다. 저장 크기는 최대 350KB이고 파일 서명을 서버에서 확인합니다. 이미지와 설정은 MongoDB `custom_foods`에 저장합니다. 개인 목록·조회·수정은 세션의 계정으로 제한합니다. 사용자가 목록에서 공개한 음식만 별도 공개 ID로 조회되며, 공개 응답에는 음식 설정·공개 ID·작성자 닉네임·공개 날짜만 포함합니다.

API: `GET/POST /api/custom-foods`, `GET/PATCH /api/custom-foods/:id`.
설정: `PATCH /api/custom-foods/:id/settings`에 `{recommendationEnabled?:boolean,published?:boolean}`. 두 설정은 독립적이며 본인만 변경할 수 있습니다.
공개 음식: `GET /api/public-foods?q=&offset=`, `GET /api/public-foods/:id`, `POST /api/public-foods/:id/import`.
쓰기 본문: `{name,tags,physics,image}`. `tags`는 기존 한국어 맛 키를 사용하고 0~1, 물리 값은 0~1(최대 늘어남은 0.3~2), 색상은 `#RRGGBB`, image는 허용된 data URL 또는 null입니다.

추천 포함 스위치는 목록에서만 변경합니다. 새 음식과 이전 저장 음식은 기본 ON이며 본인 계정의 최종 추천 후보에만 추가됩니다. 기본 감각 카드 묶음은 별도로 유지됩니다. OFF는 새 추천 계산부터 적용되고 과거 선정·추천 기록은 남습니다. 추천 계산의 메뉴 ID는 `custom:<개인 음식 ID>`로 기본 음식과 구분합니다.

공개는 기본 OFF입니다. 공개한 음식은 편집 시 공개 미리보기도 갱신됩니다. 가져오기는 설정과 그림을 독립 복사하며 작성자 닉네임을 남깁니다. 복사본은 추천 ON·공개 OFF로 시작합니다. 계정+원본 공개 ID의 고유 인덱스로 동시·반복 가져오기도 중복 생성하지 않습니다. 공개 취소하면 검색·미리보기·가져오기가 즉시 중단되며 이미 가져간 복사본은 유지됩니다.

하루 공유 버튼은 날짜 카드를 펼친 내용 안에 있습니다. 하루에 하나 이상의 선정 메뉴가 있으면 날짜·세 끼 이름으로 `/share?type=day&date=...` 링크를 만듭니다. 계정·추천 기록 ID는 공유하지 않으며 과거 날짜도 화면에 표시된 메뉴로 공유합니다. 공유 후 메뉴를 다시 골라도 기존 링크의 내용은 유지됩니다.

기존 `components/SensoryObject.tsx`와 인증·기록 API는 유지합니다. 스타일은 `ac-` 이름으로 분리합니다.
